# Wake-word model

The wake-word model bundled with this project is derived from the **sherpa-onnx** project by the [k2-fsa](https://github.com/k2-fsa) team.

The original model files are from the sherpa-onnx **GigaSpeech Zipformer KWS** release:

https://github.com/k2-fsa/sherpa-onnx/releases/tag/kws-models

Model directory:

`sherpa-onnx-kws-zipformer-gigaspeech-3.3M-2024-01-01`
